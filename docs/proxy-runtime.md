# 代理运行时适配

`egress` 包只负责代理运行时，不读写 ARTEX 任务或数据库。

## Resin

`ResinConfig` 的数据面地址由上层根据 `host/port/protocol` 生成；`ResinPlatform`
用于粘性平台名，管理地址和管理令牌只用于控制面探测及回收租约。`Probe` 会检查
`healthz`、认证模式和分页平台列表。`Release` 通过平台 ID 删除指定账号键的租约，
平台或租约不存在时按幂等成功处理。令牌不进入日志或错误文本。

租约进入 `releasing` 或 `uncertain` 后禁止自动重试回收或重新使用，须先人工核对。
已确认 `released` 的租约，只能凭仍有效、属于该任务的正式操作上下文重新获取；
仅有任务 ID、活动计数或 `context.Background()` 不构成准入证明。终态 MainAgent
可通过新一轮正式准入重获租约；上下文取消或操作结束后，原凭证失效。

## 轻量 WARP

`NewWarpManager(dir)` 使用每档案独立目录，创建时先持久化注册意图，再调用固定的
`wgcf` 和 `wireproxy`。注册返回不确定时保存 `registration_attempted` 并拒绝自动重复。
每档案使用本机回环 SOCKS5 端口，认证文件和配置文件权限为 `0600`；进程输出丢弃，
异常退出只更新通用状态，不写入工具原文。`Start` 会等待监听并通过 Cloudflare Trace
确认公网 IP 与 `warp=on/plus`，`Stop`、`Delete` 和 `Restore` 都受同一把互斥锁保护。

真实 WARP 注册必须先由用户明确确认服务条款，再向注册端点发送
`{"accept_terms":true}`；取消确认时不发送请求，不默认代为接受条款。

## 任务模式与覆盖边界

任务模式为 `inherit`、`direct`、`fixed`，创建事务保存代理选择及有效快照。
任务 LLM 出口优先级为：任务 `direct` → 任务 `fixed` → 渠道显式 LLM 代理 →
创建时保存的全局代理快照 → 直连。任务工具使用任务快照；后续全局默认变化不改写
既有快照。非任务 LLM 优先使用渠道显式代理，未配置时继承当前全局默认。

实际代理启用严格模式，解析或连接失败不回退直连；`direct` 不继承环境代理。
已接入的 Bash、WebFetch、浏览器、HTTP 自定义工具和任务 LLM 使用各自解析的出口。
不保证原始 TCP、DNS，以及忽略 HTTP/SOCKS 代理参数或环境变量的命令走任务代理。

暂停、取消或写入终态不代表工具已经退出。活动引用保留到实际操作及工具清理结束，
有占用时拒绝人工回收和代理停删改。异常退出遗留的活动引用保留保护，启动时不自动
清空；须核实没有存活使用者及未完成回收，再人工处理。

## 密钥备份与恢复

代理凭据使用独立于 JWT 的加密密钥。路径由 `ARTEX_PROXY_SECRETS_FILE` 指定，
默认是数据目录下的 `proxy-secrets/key`。备份数据库时同时安全备份原密钥，并保留
代理运行时的 WARP 档案和 Resin 租约记录；不要将密钥写进文档、日志或版本库。

恢复时使用与数据库密文匹配的原密钥及运行时记录。JWT 密钥或新生成的代理密钥
不能解密旧凭据；密钥损坏或凭据解密失败会阻止启动，不能靠清除状态强行恢复出口。
